functions Ch 1: What is a Function? (8.F.A.1)

A relation is any set of input-output pairs. A function is a special relation where each input has exactly one output. The x-value cannot repeat with different y-values. The y-value may repeat.

Domain (定义域) / Input (输入)

All possible x-values. These are the numbers you put in.

Range (值域) / Output (输出)

All possible y-values. These are the results that come out.

Independent Variable (自变量)

The input. It stands alone. It does not depend on the other variable.

Dependent Variable (因变量)

The output. It depends on the input value.

Function test

  • • Same x cannot point to two y-values.
  • • Mapping: one arrow out of each input.
  • • Graph: passes the vertical line test.
  • • Table: x-values are unique.

Not a function

  • • Input 2 gives y = 3 and y = 6.
  • • Mapping has one input with two arrows.
  • • Vertical line touches graph twice.
  • • Table repeats x with different y.

EAL sentence frame

“This relation is / is not a function because the x-value(s) do / do not repeat.”

Worked Example A

{(0,1), (1,3), (2,5), (3,7)}

All x-values are different.

Function

Worked Example B

{(0,1), (2,4), (2,6), (5,7)}

x = 2 repeats with two outputs.

Not a Function

calculate Ch 2: Evaluate Functions and Function Notation

Function notation is a short way to name a rule. f(x) means “the output when the input is x.” To evaluate, substitute the input and simplify.

Example 1: Evaluate f(x) = x - 7 when x = 5

f(5) = 5 - 7

f(5) = -2

Example 2: Evaluate g(h) = h² - 1 when h = -3

g(-3) = (-3)² - 1

g(-3) = 9 - 1

g(-3) = 8

Example 3: If j(x) = (2x - 5) / 7, find x when j(x) = -3

-3 = (2x - 5) / 7

-21 = 2x - 5

-16 = 2x

x = -8

EAL tip

Input goes inside the brackets.

Output is the value after you calculate.

Quick check

f(x)=3x+1, find f(2).

Answer: 7

Quick check

g(x)=x+3 and g(x)=10. Find x.

Answer: 7

Quick check

h(a)=a²-5 and h(a)=11. Find a.

Answer: 4 or -4

compare_arrows Ch 3: Compare Functions in Different Forms (8.F.A.2)

You may compare a graph, a table, an equation, or a verbal rule. The two big ideas are slope / rate of change and y-intercept / initial value.

Vacation: The Beach House Rental

House 1: Shore Thing

m = 200
b = 200

House 2: Beachy Keen

Equation: y = 100 + 249x

m = 249
b = 100

m = 230
b = 115

Comparison steps

  1. Find the slope of each function.
  2. Find the y-intercept of each function.
  3. Compare which grows faster.
  4. Compare which starts higher.

gesture Ch 4: Linear vs. Non-Linear (8.F.A.3)

A linear function makes a straight line and has a constant rate of change. A non-linear function does not.

Linear (直线)
  • Graph: straight line
  • Equation: can be written as y = mx + b
  • Table: same change in y every time
  • Examples: y = -x, y = 0.5x + 1
Non-Linear (非直线)
  • Graph: curve or changing direction
  • Equation: may have powers like x² or x³, or variable in denominator
  • Table: changes in y are not constant
  • Examples: A = s², y = 10/x

Myth 1

If an equation has x and y, it is linear.

False

Myth 2

If a graph goes up, it is linear.

False

Truth

Use the straight-line test and constant-rate test.

Always check both.

Speak Like a Mathematician

“This function is linear because its graph is a straight line and the y-values change by a constant amount.”

“This function is non-linear because its graph is not a straight line and the rate of change is changing.”

show_chart Ch 5: Slope, Intercepts, and y = mx + b

The slope tells how fast the line rises or falls. The y-intercept tells where the graph starts when x = 0.

Positive slope

Rises left to right

Negative slope

Falls left to right

Zero slope

Horizontal line

Undefined slope

Vertical line

Slope from two points

m = (y₂ - y₁) / (x₂ - x₁)

Through (2, 5) and (3, 9):

m = (9 - 5) / (3 - 2) = 4

Equation form

y = mx + b

m = slope

b = y-intercept

Example: y = 3x - 4 has slope 3 and y-intercept -4.

Graph from equation

1. Plot the y-intercept.

2. Use rise/run.

3. Draw arrows on both ends.

Equation from table

1. Find constant change.

2. That is slope.

3. Use x = 0 row to find b.

Intercept reminder

x-intercept is where y = 0.

y-intercept is where x = 0.

monitoring Ch 7: Read Graphs Like Stories (8.F.B.5)

Distance vs. Time Language

  • 🏃 Steeper line = faster speed
  • ➖ Flat line = stopped / resting
  • 📈 Increasing line = moving away
  • 📉 Decreasing line = coming back / getting closer
  • ↩️ Turn around = direction changes
  • 🌀 Curved graph = speed changes, not constant

Runner 2 starts slow, speeds up, falls, then sprints to finish first.

Runner 3 is steady and fast, then gets passed at the end.

Commute graph clues

One car slows down. One car stops for breakfast. One car turns around and goes back home. Read every segment, not just the first one.

architecture Ch 8: Tiny Home Geometry Link

Functions and geometry connect in the Tiny Home project. You used scale drawings, proportional reasoning, and even a linear rule for a ramp on the floor plan.

Scale 1:50

1 cm on the drawing = 50 cm in real life.

Example: 8 cm on the drawing means 8 × 50 = 400 cm = 4 m in real life.

Ramp rule

On the drawing, the ramp follows y = 1/2x + 1.

The slope means the ramp rises 1 cm for every 2 cm across on the drawing.

Connection sentence: “Scale changes the size, but the ratio stays the same. A linear rule can describe the top edge of a ramp on a scaled drawing.”
